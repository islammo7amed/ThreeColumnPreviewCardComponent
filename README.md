# ThreeColumnPreviewCardComponent
This project is a solution to the **3 Column Preview Card Component** challenge from [Frontend Mentor](https://www.frontendmentor.io/challenges/3column-preview-card-component-pH92eAR2-).  
The goal of this challenge is to build a responsive card layout that closely matches the provided design using only **HTML** and **CSS**.

## Overview
The component consists of three cards representing different car categories (Sedans, SUVs, and Luxury).  
Each card includes an icon, a title, a short description, and a call-to-action button.  
The layout adapts seamlessly between mobile and desktop screen sizes.

## Features
- Responsive layout using **Flexbox**
- Mobile-first design approach
- Clean and semantic HTML structure
- Custom Google Fonts integration
- Smooth hover effects on buttons

## Built With
- HTML5
- CSS3
- Flexbox
- Google Fonts (Big Shoulders Display & Lexend Deca)

## Responsive Design
- **Mobile view**: Cards are stacked vertically
- **Desktop view**: Cards are displayed in a three-column layout
